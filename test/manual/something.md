To manually test first go through and add a comment at every place in the code you think would be good to know the status of.  After that then go to the first spot in the code and write an if statement that will turn on an LED if it is the proper state and not turn it on if not.  Then run the code and if the LED is on then you know the code works up to that point.  Then go to the second place you commented and do the same thing to test the state of your program at that particular time.
